# Подключение пробного CrossTalk к Codex

Пакет предлагает сохранять полезные находки из работы в местные `.txt`. Владелец
соглашается на каждую находку. Подключение форума, отправка сообщений и фоновая
работа в этот пакет не входят. Установка проверена на Windows; Claude пока не поддерживается.

## Для пользователя

1. Отправь в Codex один раз:

   > Установи скилл CrossTalk из https://github.com/dadadapochito/crosstalk-skill и включи предложения полезных находок.

2. Для первой проверки начни обычный новый рабочий чат. Дай реальную задачу на
   исправление ошибки, не упоминая CrossTalk. После полезного проверенного результата
   агент должен предложить сохранить заметку. На обычной косметической правке
   предложения быть не должно.

Выключение: попроси Codex «Выключи предложения CrossTalk во всех моих чатах».
Настройки и уже созданные заметки останутся на компьютере.

## Для агента, выполняющего установку

Нужен Python 3.10 или новее. Для скачивания пакета нужен доступ к GitHub;
сам установщик не использует сеть или сторонние библиотеки.
Используй доступный Python, при необходимости — встроенную среду Codex.
Если ещё нет локальной копии, скачай репозиторий или только папку
`skills/crosstalk-share-trial`. Можно использовать стандартный установщик скиллов
Codex с `--repo dadadapochito/crosstalk-skill --path skills/crosstalk-share-trial`,
если он доступен. Установщик скиллов только копирует папку: затем обязательно
выполни следующие команды из этой папки, в том числе если она уже находится
в личном каталоге `skills`:

```text
python install.py install --enable-proposals
python install.py check
```

`--enable-proposals` фиксирует явное согласие на предложения. Без этого флага новая
установка создаёт выключенные настройки; существующий выбор владельца сохраняется.
Повторная установка с флагом явно включает предложения снова.
При просьбе только скачать пакет или обновить файлы не включай ранее отключённые
предложения. Кратко объясни владельцу, что подключение добавляет правило в личные
инструкции для рабочих чатов и что каждая заметка всё равно требует его согласия.

По умолчанию используется `CODEX_HOME`, а если он не задан — `~/.codex`.
`--codex-home "путь"` позволяет проверить установку в отдельной папке, не затрагивая
настоящий профиль. Установщик добавляет только:

- скилл вместе с этой инструкцией и установщиком в `skills/crosstalk-share-trial`;
- отдельный блок в действующий личный `AGENTS.md` или непустой `AGENTS.override.md`;
- настройку `crosstalk/preferences.json` с режимом `local_txt`.

Существующие инструкции, исключённые проекты и дополнительные поля настроек
сохраняются. При несовпадении уже установленных файлов скилла или неизвестном формате
настроек установщик останавливается до записи. Не удаляй чужие файлы ради повторной
установки. Полное обновление отличающейся версии в этом прототипе не автоматизировано.

`check` проверяет файлы и настройки: `files_ready: true` означает корректную сборку
подключения, `proposals_enabled: true` — включённые предложения. `runtime_verified`
остаётся `false`: команда не запускает модель и не доказывает срабатывание в чате.
Настройки Codex, отключающие отдельные скиллы, также могут влиять на доступность.
Не сообщай о полном подключении, если файлы не готовы или запрошенные предложения
не включены. Предложи первую проверку в новом рабочем чате; если скилл не появился,
перезапусти Codex. Не отправляй напоминания о скилле в соседние рабочие чаты.

После просьбы владельца выключить предложения:

```text
python install.py disable
```

Команда меняет только `enabled` на `false`; черновики и общие инструкции не удаляет.
Если пакет уже недоступен, агент может выключить то же поле в личном файле настроек,
сохранив остальные поля. Не переключай режим в публичную отправку: её здесь нет.

## Что уже подтверждено

На тестовом Windows-компьютере проверены чистая установка, повторная установка,
сохранение пользовательских настроек и выключение. Отдельный обычный запуск Codex
с чистой историей сам предложил заметку после исправления ошибки, без подсказки о
CrossTalk в рабочем запросе. Для этого использовались скилл и постоянное правило.
Один скилл без такого правила в первоначальной пробе предложение пропустил.

Это подтверждение конкретного сценария, а не гарантия каждого срабатывания.
Частота пропусков, лишних предложений, работа в длинных чатах, на другом компьютере
и в Claude ещё требуют проверки.

Основа подключения: [скиллы Codex](https://learn.chatgpt.com/docs/build-skills)
и [личные инструкции](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
