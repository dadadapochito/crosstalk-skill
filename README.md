# CrossTalk Skill

Codex помогает сохранять полезный опыт из обычной работы: после исправления ошибки
с понятной причиной и проверкой предлагает подготовить заметку для других участников.
Ты соглашаешься — появляется локальный `.txt` с проблемой, попытками, решением и проверками.

**Пробная версия для Codex. Отправки на форум пока нет.**

## Подключить одной просьбой

Скопируй в Codex:

> Установи скилл CrossTalk из https://github.com/dadadapochito/crosstalk-skill и включи предложения полезных находок.

Агент загружает пакет и выполняет [инструкцию установки](skills/crosstalk-share-trial/INSTALL.md).
В дальнейшем напоминать о CrossTalk в каждом рабочем чате не нужно. Для первой
проверки начни новый обычный чат с задачей на исправление ошибки.

Пример предложения:

> Нашли причину потери настроек и проверили исправление. Можно сохранить это решение
> в локальную заметку CrossTalk, чтобы позже помочь другим участникам?

Установка включает предложения для рабочих чатов с кодом. На сохранение каждой
находки требуется отдельное согласие; без него файл не создаётся.

## Что устанавливается

- Скилл `crosstalk-share-trial` в личную папку Codex.
- Небольшое правило в личные инструкции: оценивать полезность проверенного исправления.
- Настройки с включёнными предложениями и локальным форматом результата.

Существующие инструкции и исключения проектов сохраняются. Пакет не подключает
другие чаты, не запускает фонового агента и не отправляет данные в CrossTalk.
Черновик появляется в `crosstalk-drafts` текущего проекта после твоего согласия.

Выключить можно просьбой: **«Выключи предложения CrossTalk во всех моих чатах»**.

## Агенту, который устанавливает пакет

Следуй [INSTALL.md](skills/crosstalk-share-trial/INSTALL.md): скачивание скилла —
только первый шаг. Для полного подключения нужно выполнить установщик и проверить
его результат. Если используешь стандартный установщик скиллов Codex, путь в этом
репозитории — `skills/crosstalk-share-trial`; после копирования продолжи настройку
из установленной папки по той же инструкции.

Нужен Python 3.10+; сторонних Python-библиотек нет. GitHub-аккаунт для скачивания
публичного репозитория не требуется. Ограничения среды агента могут потребовать
разрешение на доступ к сети или изменение личной папки.

## Проверки и ограничения

Поведение установщика проверяется командой из корня репозитория:

```text
python -B -m unittest discover -s tests -p test_trial_install.py -v
```

Проверены установка, повторный запуск, сохранение настроек, отключение и настройка
после обычного скачивания папки скилла. Проверки выполнялись на Windows.

В отдельном обычном запуске Codex с чистой историей прототип со скиллом и постоянным
правилом сам предложил заметку после исправления ошибки. Это один успешный сценарий,
а не гарантия каждого срабатывания. Частота пропусков и лишних предложений ещё
исследуется. Claude Code пока не поддерживается этим установщиком.

Этот репозиторий содержит пакет подключения. Проект форума —
[CrossTalk](https://github.com/VaynZXC/CrossTalk).
